STEM設問の定型文

Which approach is most effective?最も効果的なのはどれか。効果の大小は「根本原因への近さ」で決まる
What is the most effective first step? / What should you check first?最初の一手は。低コストで効く手（ツール説明の見直しなど）が正解
What is the most likely root cause?最も可能性の高い根本原因は。状況文に犯人が書いてある
Which … directly addresses the root cause?根本原因に直接対処するのは。対症療法は落とす
How should you evaluate this proposal?この提案をどう評価すべきか。「一部だけ採用」が正解になりやすい
What is the primary technical limitation?主な技術的制約は。「遅い」ではなく「仕組み上できない」を選ぶ
What determines this decision?何がこの判断を決めるか。仕様上の決定要因（stop_reasonなど）
What is the main advantage of …?主な利点は。速度やコストなど副次的な利点は誤答になりやすい
Which combination correctly matches …?正しい組み合わせは。項目ごとに判定してから消去する
Which fix … while maintaining / preserving …?〜を保ったまま直すのは。後半が制約条件。無視した選択肢は誤答

PAIR対で覚える語

synchronous ⇔ asynchronous同期／非同期
blocking ⇔ non-blocking人を待たせる／待たせない。バッチ可否の判断軸そのもの
deterministic ⇔ probabilistic決定論的／確率的。フックとプロンプトの差
transient ⇔ persistent一時的／恒久的。再試行して意味があるかどうか
required ⇔ optional ⇔ nullable必須／任意／null許容
upstream ⇔ downstream上流／下流のエージェント
take precedence over / override / shadow優先される／上書きする／隠してしまう
explicit ⇔ implicit明示的／暗黙的。暗黙は誤答寄り
fine-grained ⇔ coarseきめ細かい／粗い
verbose ⇔ concise冗長／簡潔

TIP時間がないときの読み方

  • 状況文は数値と but・howeverだけ拾う。前半の説明は背景で、争点はほぼ逆接の後にある
  • 設問文を先に読んでから状況文に戻ると、探す情報が絞れる
  • 4択は誤答の匂いから消す。誰かに手間を押しつける案、モデルの善意頼みの案、後処理で隠す案は落ちる
  • 2つに絞れたら、制約条件を書いた部分（while …, without …, but the team rejected …）に戻る。片方は必ずそこに違反している
  • 未回答に減点はない。迷ったら根本原因に一番近い選択肢を選んで進む
