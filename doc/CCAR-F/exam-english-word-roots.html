homo / hetero とその仲間

homogeneous同質の、均質の。homo（同じ）+ gene（種）
heterogeneous異質の、ばらばらの。実務英語ではこちらが標準
heterogeneous documents＝形式の異なる文書群
inhomogeneous同じく「不均質な」。数学や物理で使う語で、この試験では出にくい
uniform / uniformly一様な、どれも同じ扱いで。handle errors uniformly
consistent / inconsistent一貫した／ばらついた。品質のブレを指す定番語
disparate / diverse互いに異なる／多様な
mixed-quality品質にばらつきのある。上流の出来が揃わない状況で出る

PRE接頭辞：否定と過不足

non- 〜でないnon-interactive, non-blocking, non-recoverable
un- / in- / im- 〜でないunambiguous（曖昧でない）, incomplete, implicit（暗黙の）
dis- 離す・逆discrepancy（食い違い）, disputed（争いのある）, distributed
mis- 誤って〜するmisroute, misidentify, misinterpret, misuse
この4語は全部「誤って〜する」。分解できれば辞書不要
over- 過剰・上からoverengineering（過剰設計）, overhead, overlap, override, oversight（監督）
under- 下・不足underlying（根底にある）, undermine（じわじわ損なう）
a- / an- 〜なしasynchronous（非同期）, atomic（分割不可の）

TIP本番で未知語に当たったら

  • まず接頭辞で符号だけ取る。non / un / in / mis が付いていれば否定、over は過剰、under は不足。それだけで選択肢の向きは判定できる
  • 語の意味が取れなくても、その語が正解の根拠になることは少ない。判断は動詞と限定語（only, rather than, without）で決まる
  • 選択肢に1つだけ難しい語が入っているときは、その語を消して読む。残りの文で正誤が判定できるよう作られている
  • 状況文の未知語は飛ばす。設問文と選択肢の未知語だけ立ち止まる
